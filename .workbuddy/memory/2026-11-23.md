
## 2026-11-23：Capacitor 打包安卓 APK

- 用 Capacitor 8.6.2 把 Phaser 游戏打包成全屏 APK：appId `cn.peos.levelup`，应用名「无限升级」
- 注意：`npx cap add android` 在沙箱下最后 editProjectSettings 步骤会失败（rm shim 报错），需手动改 `app/build.gradle` 的 namespace/applicationId 和 `strings.xml` 的包名/应用名（模板占位符 com.getcapacitor.myapp）
- 全屏：MainActivity 加了 WindowCompat/WindowInsetsControllerCompat 沉浸式隐藏系统栏 + FLAG_KEEP_SCREEN_ON
- 服务器地址：APK 构建用 `VITE_SERVER_URL=https://game.peos.cn`（生产同源逻辑被 env 覆盖），已加 npm 脚本 `android:apk`（cross-env）
- 产物：android/app/build/outputs/apk/debug/app-debug.apk（4.5MB，gradle 首次构建约 8 分钟）
- 线上地址：https://game.peos.cn
