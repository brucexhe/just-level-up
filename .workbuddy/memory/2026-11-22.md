# 2026-11-22

## 移动端方案调研（仅推荐，未改动代码）

- 项目现状：战场输入集中在 `client/game/scenes/StageBattleScene.ts`，方向键移动、左键选怪/普攻、右键 `moveTo`；UI 是 1200×720 DOM 叠层（`client/ui/`）。全项目无触摸/摇杆/gamepad 代码，纯手机无法移动。
- 给用户的推荐方向：
  - 方案 A（首选，适配本 ARPG）：点地移动 + 动作按钮。画布 tap → `session.moveTo`，点怪 → `session.target`，按钮映射 Space/Q/W/E/R/Z/X/F；复用已有网络意图，改动最小。
  - 方案 B：虚拟摇杆 + 技能按钮。首选 `phaser3-rex-plugins` 的 VirtualJoystick（Phaser 内建视角，`angle/force/createCursorKeys`，`fixed:true` 固定屏幕）；注意当前 Phaser 3.70，rex npm 最新 1.80.20 对应 Phaser 3.80，需锁 1.70.x 或升级 Phaser。DOM 叠层方案可用 `nipplejs` 1.0.4（TS 类型内置、static/dynamic、多点触控）。
  - 不推荐：`phaser-plugin-virtual-gamepad`（Phaser 2 时代）、VirtualJoystick.js（老旧）。
  - Phaser 官方 On-screen touch controls pack（2026-10 发布，免费）依赖 world-screen + typography，且面向新版 Phaser kernel，暂不适合 3.70。
- 手机化非输入注意点：横屏 + safe-area、CSS `touch-action:none`、按钮 ≥44px、HTTPS/WSS、音频手势解锁（项目已有）、DPR 上限 2（项目已有）。

## 方案 B 实施（已改代码，未跑验证）

- 用户选择：rex VirtualJoystick、仅 `(pointer: coarse)` 显示、范围=战场操控+移动 UI、按钮只做普攻+4 技能。
- 关键事实纠正：`pnpm-lock.yaml` 实际锁 phaser 3.90.0；rex 无 1.70.x，装 `phaser3-rex-plugins@1.80.20`（exact）。rex 的 `angle` 是度数、`rotation` 才是弧度；`.d.ts` 注释写错。
- 已新增：`client/game/input/touchEnv.ts`、`tests/touch-env.test.ts`、`client/game/scenes/TouchUiScene.ts`、`client/ui/touch.ts`。
- 已改：`StageBattleScene.ts`（触屏接线、`update()` 方向链 dead 守卫、`pointerdown` 防穿透、`GAME_CONFIG.input.activePointers=3`、scene 注册 TouchUiScene、`__demo.setTouchDir`）、`index.html`（viewport-fit + touch-root/safe-area-probe）、`ui.css`（全部 `@media (pointer: coarse)` 内）、`package.json`（新增 exact 依赖）。
- 服务端/协议/网络层未改。PC 侧不启动 TouchUiScene、不创建 DOM 按钮。
- **手机断线修复**：根因是 `main.ts` 监听 `pagehide` → 切后台/锁屏即主动 `session.dispose()` 退房，回前台必弹"连接已断开"。已改为：1) 移除 pagehide dispose（真正关页由服务端心跳超时清人）；2) `lvup:disconnect` 时先自动 `location.reload()` 重连（sessionStorage 计数 ≤2 次），成功连上后清零计数，连续失败才弹 `showBlocking` 弹窗，避免服务器宕机时无限刷新。
- **第二处断线根因（移动就断）**：rex 摇杆 update 事件每帧触发 → 触屏 dir 消息约 60 条/s，超过服务端 `MAX_MSG_PER_SEC: 30`（shared/config.ts:31），Colyseus 对超限客户端直接 forciblyCloseClient 断线。修复：`TouchUiScene.emitDirection()` 对方向量化 24 档（15°）+ 最小 60ms 上报间隔（~16 条/s）；PC 键盘 8 向离散不受影响，服务端限速未动。
- **阻塞**：本会话 Bash/PowerShell 子进程创建持续 0xC0000005 崩溃，无法执行 `pnpm install`、typecheck、test 或 dev。需用户在本地跑 `pnpm install && npm run typecheck && npm test` 验证；pnpm-lock.yaml 尚未更新。
