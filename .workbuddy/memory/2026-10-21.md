## 无限升级：补齐面板系统 + DOM UI 层（大改）

用户要求：把游戏做完善一点，加人物属性面板 / 装备面板 / 技能面板，入口都放底部工具栏，面板要好看。

### 架构决定
- **UI 从 Phaser canvas 迁到 DOM 覆盖层**（`src/ui/`），Phaser 只保留世界 + 顶部 HUD + 小地图。
  原因：CSS 做渐变/圆角/滚动/悬浮比 Phaser Text 好写太多。
- 画布尺寸 960×600 → **1200×720**；`#app` 用 `aspect-ratio: 1200/720` + `width: min(1200px, 96vw, 130vh)` 保证无黑边。
- `#ui-root` 用 `transform: scale(hostWidth/1200)` 对齐画布，所有 UI 尺寸按 1200×720 设计稿写。
- 面板停靠在左右两侧（`.dock-left` / `.dock-right`），不遮挡中间战斗区；同一侧只开一个面板。

### 新增/改动文件
- `src/data/attrs.ts` `src/data/items.ts` `src/data/skills.ts`（静态配置）
- `src/core/skills.ts`（技能书掉落 / 技能威力 / 升级消耗 / 描述生成）
- `src/core/equipment.ts`：EquipmentItem 加 `rarity` + `sourceLevel`，`rarityForRatio()` 按"点数/怪等级"的比例定稀有度
- `src/state/gameState.ts`：加 `skillPoints / skillBooks / skills`，新增 `equipBest / sellEquippedItem / useSkillBook / sellSkillBook / upgradeSkill / powerScore / equipmentStats`
- `src/ui/ui.css` `dom.ts` `api.ts` `panels.ts` `index.ts`（5 个面板 + 底部工具栏 + 技能槽 + toast）
- `src/game/scenes/StageBattleScene.ts`：删掉旧 Phaser 加点面板与技能栏，接入 GameUI；4 技能、怪物等级标签、Boss（每 10 级顶格刷 1 只，HP×8）
- 删除 `src/game/skills.ts`（合并进 `src/data/skills.ts`）

### 踩过的坑（重要）
1. `#shell { line-height: 0 }`（为消除 canvas 底部空隙）会**被继承进 UI**，导致所有文字行高 0、块高塌陷、文字重叠。`#ui-root` 必须显式 `line-height: 1.5`。
2. 重置样式 `#ui-root button { background:none; border:0 }` 的 ID 特异性会压过 `.btn/.tool/.slot`，要用 `:where(#ui-root) button` 降到 0 特异性。
3. `.dock` 即使没有面板也要 `pointer-events: none`，只有 `.panel` 是 auto，否则关掉面板后那块区域会挡住画布点击。
4. 面板内自动滚动定位：`.panel-body` 需要 `position: relative`，否则子元素 `offsetTop` 相对 `.panel` 计算会滚过头。
5. `vitest` 在此环境多 worker 并行会 EPERM（临时目录写竞争），`vitest.config.ts` 加 `fileParallelism: false` 后稳定。

### 设计遵守
- 加点仍是**纯手动**（+1 / +5 / MAX 只是批量点击，没有自动分配）。
- 金币只买药；卖装备/技能书只给点数不给金币；技能点升级消耗 = 当前技能等级。
- 新增：技能书 45% 掉率（Boss 必掉）、背包里"使用=学会 / 已学会=转技能点"。

- `tsc --noEmit` ✔ / `vitest` 49 tests ✔（新增 tests/skills.test.ts、tests/ui.test.ts）/ `vite build` ✔
- Playwright 冒烟：无 console 错误；点击穿透、面板开关、装备/加点/学技能/买药全链路可用。

## 第二轮：左上角 HUD 迁 DOM + 小地图重做 + 修「✕ 关不掉面板」

## 第五轮：音频 / 挥砍动画 / 设置面板 / 存档

用户要求：① 背景音乐（代码生成）② 战斗打击音效 ③ 普通动画（挥刀）④ 底部工具栏加设置（暂停 / 备份恢复重置 / 开关音乐）。

### `src/game/audio.ts`（新增，纯 Web Audio 合成，零音频资源）
- **BGM**：`stepEvents(step)` 纯函数按 16 分音符输出音符事件，88 BPM，Am-F-C-G 四小节循环
  （三角波贝斯 + 方波琶音 + 合成底鼓/军鼓/踩镲）；`setInterval(40ms)` + 0.2s lookahead 调度，

- **音效**：`play(name)` 15 种（swing/hit/crit/hurt/kill/boss/levelup/fire/frenzy/poison/coin/click/heal/equip/die），
  全部用 `tone()`（振荡器 + 三个 gain 关键帧）与 `noise()`（白噪 buffer + biquad 扫频）拼出来。
- **自动播放策略**：`AudioContext` 惰性创建，`unlock()` 由第一次 `pointerdown`/`keydown` 触发（场景 `unlockAudioOnGesture`）。
- **无 AudioContext 环境**（node/SSR）所有方法安全空转；`attach(ctx)` 供测试注入假 ctx。

### `src/state/save.ts`（新增）
- 主存档 / 备份双槽（`level-up/save/v1`、`level-up/backup/v1`、`level-up/prefs/v1`），

### 挥砍动画

## 第六轮：面板再缩 / 关卡限量刷怪 / 挥砍可见性 / 减伤公式修正

### 1. 面板再小一号（`ui.css`）

### 2. 挥砍动画「看不见」的真因
`slashEffect` / `swingBlade` 的 `setDepth(6/7)` 被角色按 y 排序的 depth（上千）压在下面，等于画在角色背后。
修：depth 改成 `this.player.y + 4/+5`；同时刀要甩到角色外（偏移 12 → 26px、scale 3.2、暖白色 `0xfff3c8`），

`tryMelee` 改为返回 boolean，`castSkill('attack')` 在没砍出去时调 `emptySwing()` —— 攻击间隔没到也一定有动作和音效；
左键点怪/点空地也立即挥一刀。

### 3. 关卡系统（限量怪物 + 次日刷新 + 手动画切关）
- `GameState` 新增 `stage / stages: Record<number, {killed, bossDead}> / stageDay`；`dayKey()` 本地日期键。
- 每关 **10 个等级 × 每级 10 只 + 1 只 BOSS = 101 只**（`STAGE_MONSTERS_PER_LEVEL`）。
- 击杀只 `recordKill()` 记账，**不再重生**；`create()` 时若 `stageDay !== today` 整关重刷。
- 切关：小地图头部 ◀ ▶ → `gotoStage()`（清怪 + 重铺 + 存盘），**不会自动进下一关**。
- **解锁死锁坑**：原本用 `maxUnlockedStage(highestMonsterLevel)`，但第 1 关最高只有 10 级怪 → 永远算不出第 2 关。
  改成 `maxStageFromProgress(stages)`：**打过本关 BOSS 才解锁下一关**。
- 小地图怪点 4.2 → 2.6（100+ 只不然糊成一片）。

### 4. 减伤公式修正（用户问「防御没用」）
旧：`K = K0(100) × 攻击方等级` → 10 级怪 K=1000，5 点防御只减伤 **0.5%**，等于没有防御。
新：`K = MIT_K0(12) + MIT_KD(1.5) × 等级`，减伤上限 `MIT_CAP = 65%`。
10 级怪：5 防 → 16%、20 防 → 43%、50 防 → 封顶 65%。
副作用：`penetration increases damage` 测试原本用 defense=500（已封顶）导致穿透无差异，改用 defense=60。

### 5. 其它
- 怪物血条高度 5 → **2.5**；`CHASE_RANGE` 420 → **300**（超出不追、不显示等级）。
- 去掉「战力」：HUD、人物面板、autoEquip toast、snapshot 全部移除（`powerScore` 函数保留但不再调用）。
- BGM 更轻快：BPM 88 → **116**，琶音从八分音符改成**十六分音符**，贝斯变短促拨弦（0.16s），
  底鼓加 6/14 步切分，音色更亮。

## Bug：F5 刷新后 HP/MP 回到初始 10

### 根因
`src/state/save.ts` 的 `normalizeState()` 用 `{ ...createInitialState(), ...字段 }` 重建状态，
但**从来没读 `r.hp` / `r.mp`** —— 血蓝永远来自初始值的 10。
以前有每秒自动回复所以没人发现；去掉自动回复后立刻暴露。

### 修法
1. `normalizeState` 末尾（装备/属性都还原之后，因为 `maxHp` 依赖已穿戴装备）补：
   `s.hp = clampCurrent(r.hp, maxHp(s))` / `s.mp = clampCurrent(r.mp, maxMp(s))`。
2. `clampCurrent(raw, max)` 判断必须基于**原值是否存在**：用 `num(r.hp, base.hp)` 兜默认值会
   让旧存档（无 hp 字段）读成初始 10 而不是满血 → 直接收 `unknown` 判断。
3. `applyState(s, heal = false)`：只有「重置存档」才回满（`heal=true`），
   「恢复备份」保留存档里的实时血蓝。
4. 新增 `keepSaveFreshOnExit()`：`beforeunload / pagehide / visibilitychange(hidden)` 立刻
   `saveState`。自动保存 20s 一次，中间掉血再刷新就会「读档回血」（相当于白嫖治疗）。

### 测试
`tests/save.test.ts` 新增 3 个：实时血蓝读回、超限夹到上限/缺失按满值、恢复备份保留血蓝。
`vitest` 97 passed。

## 重做升级经验曲线：从「1 只怪 1 级」改为幂律 5×L^1.5

### 用户诉求
「10 级升 11 级要 11 点经验，杀一只 11 级怪就够，基本一只怪一级，不合理」。
给了两个方案：①线性 10×L；②指数。并要求分析他自己给的四点
（10 级→10、20 级→40、30 级→90、100 级→10000）是否合理。

### 结论（已落地）
**选幂律 `expToNext(L) = 5 × L^1.5`**，杀同级怪升一级约需 `5×√L` 只：
Lv1→5 只、Lv10→16 只、Lv100→50 只、Lv1000→159 只、Lv10000→500 只。

**否定方案一（线性 10×L）的理由**：怪的经验收益 = 怪等级 ≈ 玩家等级 L（线性），
需求也是 ∝L 的话，"几只怪升一级"就是常数，等级再高也感觉不到变难，
而且**完全达不到"1 万级后变难"这个目标**。

**否定真·指数的理由**：×1.01^L 到 1 万级时单级需求 ≈ 8e43，一次击杀只给 1e4，
等于 8e39 杀升一级 —— 死路；且违背 PLAN.md §3.1「禁止复利乘法成长」的红线。

**用户那四个点不成立**（已如实说明）：前三点 (10→10, 20→40, 30→90) 完美符合 `L²/10`，
但第四点 100 级→10000 不符合（`100²/10 = 1000`）；要凑出 10000 需指数取 3，
那样 20 级→80、30 级→270，又和前三点矛盾。**四个点不在同一条曲线上**。
更要命的是：就算按 `L²/10`，10 级要 10 经验、杀一只 10 级怪给 10 经验 —— **还是一只怪一级**，
根本没解决他提出的问题。根源不是系数大小，而是需求必须比收益（∝L）长得快。

**幂律 1.5 为什么正好**：累积经验 ∝ L^2.5，落在主流 RPG 区间
（魔兽 ≈ L^2.1、RuneScape ≈ L^2.5、FF ≈ L^2~L^3）。

### 顺带确认的一个结构性安全点
关卡等级段是**固定的**（第 k 关 = 10k-9..10k），而需求是超线性的，
理论上玩家等级会落后于关卡段。但**掉队会自动追回来**：
等级 L 打 M 级怪，每杀给 M 点经验、需求只有 5·L^1.5，等级越低升得越快；
再加上高级怪掉的高级装备点数（∝ 怪等级 × 部位数）远超等级本身，
所以玩家不会被永久卡在某个 BOSS 前面。这条已写进 PLAN.md。
