# 2026-10-21

## 无限升级：补齐面板系统 + DOM UI 层（大改）

用户要求：把游戏做完善一点，加人物属性面板 / 装备面板 / 技能面板，入口都放底部工具栏，面板要好看。

### 架构决定
- **UI 从 Phaser canvas 迁到 DOM 覆盖层**（`src/ui/`），Phaser 只保留世界 + 顶部 HUD + 小地图。
  原因：CSS 做渐变/圆角/滚动/悬浮比 Phaser Text 好写太多。
- 画布尺寸 960×600 → **1200×720**；`#app` 用 `aspect-ratio: 1200/720` + `width: min(1200px, 96vw, 130vh)` 保证无黑边。
- `#ui-root` 用 `transform: scale(hostWidth/1200)` 对齐画布，所有 UI 尺寸按 1200×720 设计稿写。
- 面板停靠在左右两侧（`.dock-left` / `.dock-right`），不遮挡中间战斗区；同一侧只开一个面板。

### 新增/改动文件
- `src/data/attrs.ts` `src/data/items.ts` `src/data/skills.ts`（静态配置）
- `src/core/skills.ts`（技能书掉落 / 技能威力 / 升级消耗 / 描述生成）
- `src/core/equipment.ts`：EquipmentItem 加 `rarity` + `sourceLevel`，`rarityForRatio()` 按"点数/怪等级"的比例定稀有度
- `src/state/gameState.ts`：加 `skillPoints / skillBooks / skills`，新增 `equipBest / sellEquippedItem / useSkillBook / sellSkillBook / upgradeSkill / powerScore / equipmentStats`
- `src/ui/ui.css` `dom.ts` `api.ts` `panels.ts` `index.ts`（5 个面板 + 底部工具栏 + 技能槽 + toast）
- `src/game/scenes/StageBattleScene.ts`：删掉旧 Phaser 加点面板与技能栏，接入 GameUI；4 技能、怪物等级标签、Boss（每 10 级顶格刷 1 只，HP×8）
- 删除 `src/game/skills.ts`（合并进 `src/data/skills.ts`）

### 踩过的坑（重要）
1. `#shell { line-height: 0 }`（为消除 canvas 底部空隙）会**被继承进 UI**，导致所有文字行高 0、块高塌陷、文字重叠。`#ui-root` 必须显式 `line-height: 1.5`。
2. 重置样式 `#ui-root button { background:none; border:0 }` 的 ID 特异性会压过 `.btn/.tool/.slot`，要用 `:where(#ui-root) button` 降到 0 特异性。
3. `.dock` 即使没有面板也要 `pointer-events: none`，只有 `.panel` 是 auto，否则关掉面板后那块区域会挡住画布点击。
4. 面板内自动滚动定位：`.panel-body` 需要 `position: relative`，否则子元素 `offsetTop` 相对 `.panel` 计算会滚过头。
5. `vitest` 在此环境多 worker 并行会 EPERM（临时目录写竞争），`vitest.config.ts` 加 `fileParallelism: false` 后稳定。

### 设计遵守
- 加点仍是**纯手动**（+1 / +5 / MAX 只是批量点击，没有自动分配）。
- 金币只买药；卖装备/技能书只给点数不给金币；技能点升级消耗 = 当前技能等级。
- 新增：技能书 45% 掉率（Boss 必掉）、背包里"使用=学会 / 已学会=转技能点"。

### 验证
- `tsc --noEmit` ✔ / `vitest` 49 tests ✔（新增 tests/skills.test.ts、tests/ui.test.ts）/ `vite build` ✔
- Playwright 冒烟：无 console 错误；点击穿透、面板开关、装备/加点/学技能/买药全链路可用。

## 第二轮：左上角 HUD 迁 DOM + 小地图重做 + 修「✕ 关不掉面板」

用户反馈三点：① 左上角血/蓝/经验条太丑，要和人物面板一致；② 右上角 ✕ 点不动；③ 小地图要显示怪物分布与人物位置。

### 关键修复：✕ 点不动的真因
`makeDraggable` 用 `left/top + right:auto/bottom:auto` 移动面板，导致 `.panel { inset: 0 }` 退化为**按内容撑开**
（348×504 → 241×965），面板高度暴涨把 ✕ 顶出视口，Playwright 报 "element is outside of the viewport"。
修法：`makeDraggable` 改为**只写 `transform: translate()`**，盒模型完全不动；用 `setPointerCapture` 保证拖拽
松手在窗口外也能结束；关闭按钮改为在 `#ui-root` 上事件委托（`[data-close]`），面板重建也点得动。

### HUD
- 删除 Phaser 版左上角 HUD（rectangle + 4 个 image bar + 4 个 text + `buildHud/updateHud`），
  改为 `#ui-root` 里的 `.hud` 卡片，**复用人物面板的 `.hero` / `.bar` 样式**，所以天然一致。
- `GameUI.updateLive` 用 `[data-live]` / `[data-w]` 统一驱动：hp/mp/exp/level/power/gold/kills/points，
  写 DOM 前先比对，避免每帧重排；hp ≤ 30% 时给 `.bar.hp` 加 `low` 类（红色 + 呼吸）。
- `.dock-left` top 124、`.dock-right` top 196，给 HUD 和小地图让位。

### 小地图
- 改为 DOM `<canvas 256×256>` 画在 `.minimap` 卡片里（缩放后仍清晰），场景通过 `GameUI.opts.minimap()` 每帧提供快照
  （world/player/monsters/obstacles/view/stage/stageName/monsterLevel）。
- 画：网格、障碍点、相机视野框、怪物（被动紫 / 主动红 / BOSS 橙色菱形带辉光）、玩家（绿色发光点 + 白边）。
- **点击地图即移动**（`opts.moveTo` → 场景 `moveToWorld`），可以照着红点去追怪。
- Phaser 侧删掉 `minimap` graphics / `stageText` / `drawMinimap`。

### 验证
- `tsc` ✔ / `vitest` 49 ✔ / `vite build` ✔
- Playwright：5 个面板 ✕ 全关；拖拽后 ✕ 仍可点、面板内按钮仍可点；HUD 数值实时；点小地图人物位移；无 console 错误。

### 环境坑
- Playwright 启动 chromium 常有 1 次失败（`Target page, context or browser has been closed`），
  用 `boot.mjs` 里的重试循环（4 次 + 800ms 间隔）即可；**千万不要 taskkill chrome.exe**（会杀掉用户浏览器）。

## 第五轮：音频 / 挥砍动画 / 设置面板 / 存档

用户要求：① 背景音乐（代码生成）② 战斗打击音效 ③ 普通动画（挥刀）④ 底部工具栏加设置（暂停 / 备份恢复重置 / 开关音乐）。

### `src/game/audio.ts`（新增，纯 Web Audio 合成，零音频资源）
- **BGM**：`stepEvents(step)` 纯函数按 16 分音符输出音符事件，88 BPM，Am-F-C-G 四小节循环
  （三角波贝斯 + 方波琶音 + 合成底鼓/军鼓/踩镲）；`setInterval(40ms)` + 0.2s lookahead 调度，
  每个音符现建 osc/gain 包络，播完自动 stop。
- **音效**：`play(name)` 15 种（swing/hit/crit/hurt/kill/boss/levelup/fire/frenzy/poison/coin/click/heal/equip/die），
  全部用 `tone()`（振荡器 + 三个 gain 关键帧）与 `noise()`（白噪 buffer + biquad 扫频）拼出来。
- **自动播放策略**：`AudioContext` 惰性创建，`unlock()` 由第一次 `pointerdown`/`keydown` 触发（场景 `unlockAudioOnGesture`）。
- **无 AudioContext 环境**（node/SSR）所有方法安全空转；`attach(ctx)` 供测试注入假 ctx。

### `src/state/save.ts`（新增）
- 主存档 / 备份双槽（`level-up/save/v1`、`level-up/backup/v1`、`level-up/prefs/v1`），
  信封 `{v, at, state}`，`normalizeState()` 逐字段校验（非法值丢弃、缺字段补默认、`equipped` 的键与 `slot` 必须一致）。
- 无 localStorage（node/隐私模式）自动退化为内存 store，所以逻辑可单测。
- 每个 20 秒自动保存（场景 `autoSave`），启动时 `loadState()` 续档。

### 挥砍动画
- 新纹理 `blade`（14×5 像素刀）+ `swingBlade(angle)`：刀绕角色从 `angle-1.3` 扫到 `angle+0.7`，170ms 淡出。
- 命中反馈：怪物 `setTintFill` + 1.18/0.82 压扁回弹（`Back.Out`）+ 击退，暴击（伤害 ≥ 50% 最大血）用 crit 音效。

### 设置面板
- `PanelId` 加 `settings`，工具栏第 6 个按钮（⚙ 快捷键 **O**），dock 在右侧。
- 暂停：`physics.world.pause()` + `tweens.pauseAll()` + `audio.setPaused()` + `.pause-veil` 遮罩；
  **关键**：暂停时 `this.time.now` 仍在走，恢复时要 `shiftTimers(dt)` 把所有未来时间点（CD、下次攻击、DoT、狂暴到期）整体后移，否则暂停期间 CD 会偷偷走完。
- 遮罩 `z-index: 1`，`.dock/.bottombar` 提到 `8`，`.hud/.minimap` 提到 `6` —— 否则面板被一起模糊，看不到「继续游戏」。
- 音量滑块用 `body.oninput` 委托（拖动时不 refresh，否则面板重建会丢焦点）。
- 重置按钮二次确认：5 秒内再点才生效（模块级 `resetArmedAt`）。
